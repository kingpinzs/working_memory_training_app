# Working Memory Lab - User Guide

## Getting Started

Working Memory Lab is a cognitive training application designed to assess and improve your working memory through scientifically-backed exercises.

### Opening the App

1. Open `index.html` in any modern web browser
2. No installation required - runs entirely in your browser
3. All data is stored locally (your privacy is protected)

## Main Navigation

The app has 5 main tabs:

### Dashboard
Your personal analytics hub showing:
- **Domain Scores**: Verbal, Spatial, and Attention percentages
- **Weekly Comparison**: This week vs last week performance
- **Streak Calendar**: Daily activity visualization
- **Real-World Wins**: Log moments when working memory helped you

### Launchpad
Access all cognitive exercises:
- **WM Span**: Verbal working memory capacity
- **Spatial+Verbal**: Combined visuospatial memory
- **Cross-modal Binding**: Color-shape associations
- **N-Back**: Classic attention/update task
- **Dual N-Back**: Position + audio simultaneous task
- **Audio N-Back**: Auditory letter matching
- **Corsi Blocks**: Visuospatial sequence memory
- **Operation Span**: Complex span with math verification
- **Filter Positive**: Selective attention task
- **Mental Math**: Arithmetic fluency

### BrainTok
Quick micro-tasks with swipeable card interface:
- **Math Flash**: Verify equations (swipe right for correct)
- **Memory Flash**: Remember and match sequences
- **Word Match**: Category classification

### Focus Timer
Pomodoro-style focus sessions with break reminders.

### Profile
Your cognitive profile and settings.

## Features

### Coach Mode
Toggle Coach Mode ON for guided sessions:
- Adaptive difficulty based on your performance
- Personalized task selection
- Progress-based recommendations

### High Contrast Mode
Accessibility feature for improved visibility:
- Toggle in the Launchpad settings
- Persists across sessions

### Personal Bests
Your best scores are tracked and celebrated:
- 🏆 Trophy icon indicates a new personal best
- Best scores shown on task cards

### Keyboard Shortcuts
- **Space**: Respond during N-Back tasks
- **Enter**: Confirm/Submit
- **Escape**: Cancel/Back
- **C**: Start Coach Session
- **R**: Retry current task

## Exercise Instructions

### WM Span
1. Watch words appear one at a time
2. Remember the sequence
3. Type words back in order
4. Level increases with correct answers

### N-Back
1. Watch emotional words appear
2. Press Space when current word matches N words back
3. Start at 1-back, progress to 2-back and 3-back
4. Accuracy determines advancement

### Spatial+Verbal
1. Watch shapes appear on triangular board
2. Remember both position and color name
3. Recall positions in sequence
4. Answer verbal verification questions

### Corsi Blocks
1. Watch blocks light up in sequence
2. Click blocks in the same order
3. Sequence length increases with success
4. Measures visuospatial span

### Filter Positive
1. Grid of emotional words appears
2. Click only positive/calm/strong words (varies by mode)
3. Accuracy and speed both matter
4. Optional countdown mode for extra challenge

## Data & Privacy

- All data stored in browser localStorage
- No data sent to external servers
- Export your data anytime (JSON or CSV)
- Reset scores from Profile tab

## Tips for Best Results

1. **Consistency**: Train regularly, even 10 minutes daily
2. **Focus**: Minimize distractions during tasks
3. **Rest**: Adequate sleep improves cognitive performance
4. **Track Lifestyle**: Log sleep and exercise in the app
5. **Challenge Yourself**: Use Coach Mode for progression
