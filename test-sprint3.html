🎯 Manual Test Checklist

Enhanced Dashboard Tests:

  • Navigate to Dashboard tab
  • Verify 3 domain score cards display (Attention, Verbal WM, Spatial WM)
  • Check trend arrows (↗↘→) and baseline comparison values
  • Click each domain card → verify drill-down chart appears
  • Click "Back to Dashboard" → verify returns to main view
  • Check streak calendar displays (12-week grid)
  • Hover over calendar squares → verify tooltips show date + session count
  • Verify current/longest streak numbers display correctly

Real-World Wins Tests:

  • From Dashboard: Click "+ Log a Win" button
  • From Launchpad: Click "🌟 Log a Win" button
  • In modal: Type a win description
  • Verify character counter updates (X/280)
  • Click Save → verify success toast appears
  • Click Cancel → verify modal closes
  • Press ESC → verify modal closes
  • Click backdrop → verify modal closes
  • Try submitting empty note → verify error toast
  • Go to Dashboard → verify win appears in "Recent Wins" section
  • Verify relative timestamp ("X minutes ago")
  • Log 6+ wins → verify "+X more wins" indicator
